# Для того, чтобы сгенерировать данные о студентах в Protege, необходимо выполнить следующие шаги
### 1. Установка и использование Protege
 1.1. Для того, чтобы скачать Protege, нужно перейти по ссылке: _https://protege.stanford.edu/products.php_
 
 1.2. После успешной установки, необходимо заменить в папке плагина cellfie для Protege .jar файл на тот, что расположен в проекте (cellfie/cellfie-2.1.1.jar)

### 2. Открыть файл _rules.owl_ в Protege
_Данный файл расположен в корне проекта._
### 3. Загрузить таблицу с данными о научных руководителях 
_(см. пункт **"Таблицы и правила"**)._
1. Во вкладке Tools, расположенной в верхнем меню, выбрать пункт _**Create axioms from Excel workbook**_ _(см. скриншот)_

   ![img.png](src/main/resources/img.png)

2. Выбираем нужную таблицу и нажимаем _**Open**_ _(см. скриншот)_

   ![img_5.png](src/main/resources/img_5.png)

3. Выбираем _**Load Rules**_ и загружаем правила для этой таблицы, после нажимаем _**Open**_ _(см. скриншот)_
   
   ![img_6.png](src/main/resources/img_6.png)

4. После того как загрузили правила, нужно сгенерировать аксиомы 

Для этого нажимаем _**Generate Axioms**_ _(см. скриншот)._

   ![img_7.png](src/main/resources/img_7.png)

5. Если ошибок при генерации нет, появится окошко _(см. скриншот)_, где нужно выбрать _**Add to current onlotogy**_
   
   ![img_8.png](src/main/resources/img_8.png)

### 7. Нормоконтроль
1) Требования по нормоконтролю описаны в онтологии (__*src/main/resources/normocontrol.owl*__). В случае, если загружается или обновляется онтология  нужно взять за основу файлы для выгрузки данных в новую онтологию (__*src/main/resources/rules/main_rules.owl*__ и __*src/main/resources/normocontrol.owl*__) и загрузить их в Protege, далее проделав пункты выше по наполнению базы знаний.
2) Необходимо установить пакеты python для корректного запуска скрипта. Для этого необходимо выполнить команды:
__*pip install nltk*__
__*python -m nltk.downloader punkt*__
__*python -m nltk.downloader stopwords*__

3) Валидация отчета и индивидуального задания осуществляется в двух режимах - через интерфейс, а также в ручном формате.
4) На интерфейсе представлены кнопки для валидации индивидуального задания и отчета (см. скриншот). По нажатию на соответсвующее направление будет осуществлена валидация отчета и индивидуального задания.
![img_5.png](img_5.png)
5) В ручном формате выбирается класс, совпадающий с названием файла для валидации. Классы расположены в пакете: **_src/main/java/normative_control/validation/runners_**. После перехода необходимо выбрать директорию с уровнем подготовки, далее - с направлением обучения.
6) Логи об успехе/неудаче нормоконтроля документов можно увидеть в консоли, а также в файлах, которые будет сгенерированы по окончанию валидации (**_файлы будут расположены в корне проекта_**).
